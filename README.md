# OLDENLAND — oldenland.com

A cinematic, scroll-driven website for Oldenland, an exporter of Persian saffron.
It follows the saffron from the field to the finished gift.

| Chapter | What happens on scroll | Tech |
|---|---|---|
| Hero · I The Field · II The Harvest | A real-time 3D saffron field at dawn. The camera flies down to a single crocus, its petals open, and its three red stigmas float out. | Three.js / React Three Fiber, custom shaders (sky, soil, wind) |
| III The Unboxing | The real unboxing film, scrubbed frame by frame with the scroll: bag → gift box → violet case → glass crocus crown → saffron. | 365-frame WebP sequence drawn to `<canvas>`, GSAP ScrollTrigger |
| IV The Craft | A pinned horizontal gallery of the five packaging layers. | GSAP pin + `containerAnimation` parallax |
| V The Saffron | An iris reveal of the macro shot, then the product specification. | GSAP timeline + clip-path |
| VI Export · Contact | Importer information and a quote-request form (opens the visitor's email app). | — |

Stack: **Next.js 16** (static export), **TypeScript**, **Tailwind CSS v4**, **GSAP + ScrollTrigger**, **Lenis** smooth scroll, **Three.js / React Three Fiber**.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static site in ./out — deploy to any static host (Vercel, Netlify, Cloudflare Pages, S3…)
```

## Media

The original photos and video are in `media/source/`. The web-ready files in `public/` are generated by:

```bash
npm run media      # needs ffmpeg (with libwebp) and ImageMagick
```

This script:
- Turns the video into graded WebP frames: `public/frames/lg` (720 px) and `public/frames/sm` (432 px).
- Turns the photos into graded WebP images at 1600 px and 800 px in `public/images`.

To swap in a new unboxing video, replace `media/source/video.mp4` and run the script again. Then update these values to match the new clip:
- `FRAME_COUNT` and `FRAME_CUT` in `lib/frames.ts`
- the stage frame ranges in `lib/content.ts`

## Editing text

All copy is in `lib/content.ts`, including the story beats, unboxing captions, specs, export points and contact details.

**Check before going live:**
- `brand.email` is a placeholder (`info@oldenland.com`).
- The `specs` values (cut and grade, ISO 3632) should match your lab reports.
